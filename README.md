This is the code respository for comparison of FANET Routing protocols 


To run this code, 3.26 version of ns3 and python 2.7.8 is required. if used with current ns3 and python versions module will not work.

To Install ns3, please follow the instructions on: https://www.nsnam.org/wiki/Installation

The example requires anthocnet module. To install anthocnet module please follow the instructions on https://github.com/Sawchord/anthocnet
